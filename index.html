GenAI / RAG

Cloud-native enterprise RAG platform

Architected a cloud native RAG platform (AWS Lambda, Claude API, LangChain, pgvector) reaching 1,000+ users, using structure aware chunking and hybrid vector + BM25 retrieval with source citations to hold accuracy near 90% on SME-validated queries.

  • AWS Lambda
  • Claude API
  • LangChain
  • pgvector
Architecture notes
  • Constraint: dense-vector-only retrieval missed exact terms (fault codes, part numbers) that technicians searched for verbatim, and unverifiable answers wouldn't earn trust.
  • Decision: hybrid vector + BM25 retrieval over structure-aware chunks, with every answer grounded in a citation back to the source document, serverless on AWS Lambda.
  • Result: 1,000+ users onboarded, ~90% accuracy on SME-validated queries, knowledge discovery cut from 40+ hours to seconds.
Agentic AI

Semi-automated decision optimization agent

Designed an MCP tool server based agent with a Random Forest optimizer proposing machine parameters in seconds, bound by hard coded control limit guardrails with human override, eliminating up to 18 daily manual tuning events across 6 machines and 3 shifts.

  • MCP
  • PostgreSQL
  • Docker
  • Kubernetes
Architecture notes
  • Constraint: automated actions touching physical machines had to stay bounded and auditable to earn engineering teams' trust.
  • Decision: MCP tool servers and PostgreSQL backed a Random Forest optimizer whose every action stays bound by hard coded control limit guardrails with human override.
  • Result: eliminated up to 18 daily manual tuning events (4.5 to 6 hours of specialist time) across 6 machines and 3 shifts.
Computer vision

Edge computer vision for cleanroom staffing

Trained a real time TensorFlow SSD model deployed to the edge via OpenVINO on Intel Movidius Neural Compute Sticks across 2 sites to rebalance staff against real time demand, using a privacy-by-design approach that never detects faces.

  • TensorFlow SSD
  • OpenVINO
  • Edge inference
  • Privacy by design
Architecture notes
  • Constraint: cloud inference latency made real-time cleanroom staffing decisions impractical, and floor-level trust required strict privacy guarantees.
  • Decision: pushed TensorFlow SSD inference to the edge on Intel Movidius NCS via OpenVINO across 2 sites, detecting PPE suits and role colored caps only, never faces.
  • Result: 16% improvement in operational efficiency, contributing to a WEF Global Lighthouse recognition.
Predictive ML

Hardware-defect risk detection pipeline

Productionized a gradient boosting risk detection pipeline through Jenkins CI/CD to identify hidden defect patterns tied to roughly $12M in annual losses, shifting decisions from reactive to proactive.

  • Gradient boosting
  • Jenkins CI/CD
  • Monitoring
  • Risk detection
Architecture notes
  • Constraint: defect patterns were rare and buried across heterogeneous production signals — manual review was reactive and too slow.
  • Decision: gradient boosting model retrained and deployed through Jenkins CI/CD with production monitoring for drift.
  • Result: flagged failure patterns tied to ~$12M in annual loss exposure, shifting the team to proactive mitigation.
