Agentic AI

Real-time decision-optimization platform

Designed a real-time AI-driven decision-optimization platform using MCP tool servers and pgvector for controlled, retrieval-grounded tool execution, containerized with Docker and Kubernetes to recommend optimized machine parameters within seconds.

  • Python
  • MCP
  • pgvector
  • Kubernetes
Architecture notes
  • Constraint: recommendations had to be generated within seconds and stay auditable — no opaque model output on the shop floor.
  • Decision: MCP tool servers scoped each retrieval call against pgvector so the model could only act on grounded, controlled context.
  • Result: containerized on Docker/Kubernetes for multi-site rollout without re-architecting per site.
RAG platform

Cloud-native enterprise knowledge platform

Architected a cloud-native RAG platform with AWS Lambda, Claude API, LangChain, and pgvector, indexing thousands of documents with structure-aware chunking and hybrid vector+BM25 retrieval — reaching 100+ users and cutting knowledge-discovery time from 40+ hours to minutes.

  • AWS Lambda
  • Claude API
  • LangChain
  • Hybrid search
Architecture notes
  • Constraint: dense-vector-only retrieval missed exact terms (part numbers, error codes) that engineers searched for verbatim.
  • Decision: hybrid vector + BM25 retrieval over structure-aware chunks, serverless on AWS Lambda to absorb bursty usage without idle cost.
  • Result: 100+ active users, knowledge discovery cut from 40+ hours to minutes.
Computer vision

Real-time production analytics pipeline

Built a real-time computer vision system with TensorFlow SSD and HLS streaming, deploying inference on an Intel Movidius Neural Compute Stick with OpenVINO at the edge, improving operational efficiency by 16% and contributing to a World Economic Forum Global Lighthouse recognition.

  • TensorFlow
  • OpenVINO
  • React
  • Node.js
Architecture notes
  • Constraint: cloud inference latency and shop-floor network reliability made a centralized model impractical for real-time utilization tracking.
  • Decision: pushed TensorFlow SSD inference to the edge on an Intel Movidius NCS via OpenVINO, streaming results over HLS to a React dashboard.
  • Result: 16% improvement in machine utilization; work contributed to a WEF Global Lighthouse recognition.
Predictive ML

Hardware-defect risk detection pipeline

Productionized a gradient boosting risk-detection pipeline, orchestrated through Jenkins CI/CD, to identify hidden defect patterns tied to ~$12M in annual losses, shifting decision-making from reactive analysis to proactive risk mitigation.

  • Gradient boosting
  • Jenkins CI/CD
  • Monitoring
  • Risk detection
Architecture notes
  • Constraint: defect patterns were rare and buried across heterogeneous production signals — manual review was reactive and too slow.
  • Decision: gradient boosting model retrained and deployed through Jenkins CI/CD with production monitoring for drift.
  • Result: flagged failure patterns tied to ~$12M in annual loss exposure, shifting the team to proactive mitigation.
